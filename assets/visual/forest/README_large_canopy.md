# ShootAndRun forest large canopy assets v1

Large deep-forest canopy and pine-cluster assets for the forest mass composition pass.

Install from the ShootAndRun project root:

```bash
unzip ~/Downloads/ShootAndRun_forest_large_canopy_assets_v1.zip -d .
```

Inspect contact sheet:

```bash
xdg-open assets/visual/forest/docs/contact_sheet_large_canopy_v1.png
```

Expected integration target:

```text
0.1.34 -> 0.1.35
forest large canopy pass
```

The pack is visual-only. It must not change collision, routes, markers or runtime grids.
