# Forest large canopy style lock

Approved direction: bright hand-painted top-down fir forest, matching `forest_assets_v2_style_locked`.

Hard rules:

- No flat triangle trees.
- No icon-like silhouettes.
- Large assets should read as dense forest mass, not single repeated symbols.
- Use dark lower shadows, olive highlights, irregular crowns and overlapping canopy.
- Use these assets only as visual objects/overlays; collision remains controlled by map_package/runtime_grids.
