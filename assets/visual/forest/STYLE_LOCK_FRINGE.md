# Forest fringe style lock

Approved direction: hand-painted top-down forest undergrowth.

This pack is not a replacement for big trees. It is a transition layer for the forest edge.

Use for:
- forest edge fringe;
- clearing border;
- undergrowth;
- visual-only shadows;
- small debris near trees.

Do not use for:
- road center;
- water core;
- ruin walls/floors;
- collision changes.
